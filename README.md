# AI Document Processing & OCR Pipeline

AI-powered document processing system built using Flask, React, OpenCV, EasyOCR, and Groq LLM.

## Features
- OCR Extraction
- PDF Processing
- Table Detection
- Bounding Box Visualization
- Document Classification
- Structured Data Extraction
- Multi-page PDF Support
- Batch Processing

## Tech Stack
- Flask
- React
- OpenCV
- EasyOCR
- Groq API
- SQLite
